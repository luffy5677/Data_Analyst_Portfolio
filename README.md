## How to use this repository

1. Open the project folder you want to study.
2. Read its `readme.md` for the dataset, tools, and workflow.
3. Open the relevant SQL, Excel, Power BI, Tableau, or Python files using the appropriate application.
4. Reproduce the analysis and add your own findings, queries, visualizations, and documentation before presenting it as your own work.
